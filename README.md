# Timeline

Личный таймлайн жизни — визуализация событий на горизонтальной оси времени с плавным зумом, панорамой, фильтрацией по значимости и кластеризацией.

## Возможности

- Canvas-сетка времени с зумом колесом и панорамой перетаскиванием
- Уровни детализации (LOD): при отдалении остаются только значимые события
- Кластеризация близких точек со счётчиком и tooltip
- Создание события кликом по оси, редактирование и удаление — кликом по точке
- Категории с иерархией и значимость 1–3
- Optimistic UI + toast-уведомления

## Стек

Next.js 15 (App Router, Server Actions) · React 19 · better-sqlite3 · Tailwind CSS 4 · TypeScript · pnpm

## Установка

```bash
pnpm install
```

База данных (`data/timeline.db`) создаётся и наполняется автоматически при первом запуске.

## Запуск

```bash
pnpm dev      # дев-сервер (Turbopack) на http://localhost:3000
pnpm build    # продакшен-сборка
pnpm start    # запуск собранного приложения
pnpm lint     # проверка ESLint
```

На Windows можно использовать `start.bat`.

## Структура

```
src/
  app/          App Router (страница и layout)
  actions/      Server Actions (CRUD событий и категорий)
  db/           SQLite-клиент, схема, сиды, запросы
  components/   timeline/ (визуализация) и ui/ (примитивы)
  lib/          проекция времени, даты, константы, утилиты
```

Подробности архитектуры и конвенций — в [CLAUDE.md](./CLAUDE.md).
