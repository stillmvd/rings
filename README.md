# Timeline

Личный таймлайн жизни — визуализация событий в четырёх режимах: Canvas-ось времени с зумом и панорамой, галерея карточек, календарь и раздел «Отслеживание». Material 3 dynamic color.

## Возможности

- **Таймлайн** — Canvas-сетка времени с зумом колесом и панорамой перетаскиванием; уровни детализации (LOD) скрывают незначимые события при отдалении; кластеризация близких точек со счётчиком и tooltip
- **Галерея** — карточки событий с медиа и скраббером по датам
- **Календарь** — месячная сетка с событиями и быстрыми отметками дня
- **Отслеживание** — отсчёты до будущих событий и годовщины прошедших с живым обратным отсчётом
- События: точечные и периоды (`end_date`), значимость 1–3, иерархические категории с иконкой и цветом
- Быстрые отметки дня без названия по справочнику типов (трекеров)
- Медиа (фото) у событий, поиск и фильтрация (по `/` или Ctrl/Cmd+F), резервное копирование
- Optimistic UI + toast-уведомления

## Стек

Next.js 15.5 (App Router, Server Actions, Turbopack) · React 19 · better-sqlite3 · Tailwind CSS 4 · @material/web · TypeScript · pnpm

## Установка

```bash
pnpm install
```

База данных (`data/timeline.db`) создаётся, наполняется и мигрируется автоматически при первом запуске.

## Запуск

```bash
pnpm dev      # дев-сервер (Turbopack) на http://localhost:3000
pnpm build    # продакшен-сборка
pnpm start    # запуск собранного приложения
pnpm lint     # проверка ESLint
npx tsc --noEmit   # проверка типов
```

На Windows можно использовать `start.bat`.

## Структура

```
src/
  app/          App Router: page.tsx (server) грузит данные → AppShell (client)
  actions/      Server Actions: события, категории, отметки, типы отметок,
                медиа, календарь, настройки, бэкап
  db/           SQLite-клиент, схема, сиды, миграции, запросы
  components/   timeline/ · gallery/ · calendar/ · tracking/ · search/ ·
                categories/ · marktypes/ · settings/ · m3/ · ui/
  lib/          проекция времени, даты, отсчёты, проекция, тики, цвета,
                фильтр, медиа, M3 dynamic color
  types/        типы кастомных Material Web элементов
```
